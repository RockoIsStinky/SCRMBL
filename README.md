# SCRMBL 
An RNG and skill-based game website, made by a cuber for cubers & gamblers!! You get one seed-based scramble each day, and share it with your cubing/gambling friends :D

## HOW IT WAS MADE
### Phase 1
Back in early September, I picked up speedcubing again after a year and a half! And one of my friends gave me my beloved WRM V9 (Red ballcore btw). And then I was trying to brainstorm a qualifier project for Citadel, and I decided, why not make another website? Is it extremely accessible on all devices?

### Phase 2
I don't want to make another generic website, because those are boring. I wanna make something niche, so that's where the idea of SCRMBL came from (It's just a bunch of things I found cool smashed together 🤤).

## WHAT MADE IT
Made by a few friends that I stole the idea from on our small Discord server.
This project was created in **Visual Studio Code** using **Three.js, HTML & CSS.**

## HOW TO INSTALL & RUN IT
1. Clone the source code by typing this in your git terminal:
   `git clone https://github.com/RockoIsStinky/RockoIsStinky.github.io.git`
2. Go to your project's directory:
   `cd SCRMBL` <- Just an example; it will change based on your cloning path
3. Install npm: `npm install`
4. Run it: `npm run dev` or `npx vite`; both work. This will just host a local web server for you!
5. Open the URL in the "Local" row: `http://localhost:1234/`. The output will be something like this:

   ```
